# 🪨📄✂️ Rock-Paper-Scissors Game  

A simple and fun **Rock-Paper-Scissors Game** built with **HTML, CSS, and JavaScript**.  
Play against the computer, enjoy interactive design, and track the winner in real time.  

---

## 🚀 Features  
- 🎮 Play against the computer with random choices
- 🏆 Score tracking for both player and computer and saved the result 
- 🖼️ Modern and responsive UI design
